## Конспекты

## Git для новичков (часть 2) — командная работа

1. git checkout -b <название_ветки> -команда для перехода на указанную ветку и плюс сразу ее открыть.
2. Имя новой ветки-кратко и ёмко называем, чтобы сразу было понятно что именно меняли в проекте. И коммиты не забываем добавлять-чтобы понимать в чем суть изменений.
3. После того как сделали новую ветку, ее нужно слить в мэйн ветку. Для этого переключаемся сначала на мейн гит чекаут мэйн, потом делаем гит пулл ориджин мейн и потом сливаем git merge <название_ветки>.
4. чтобы др.чел или я смогли получить актуальую инфо с гитхаба нужно загрузить себе при помощи команды git clone <адрес_репозитория> (адрес репозитория в зел.кнопке CODE)
5. git diff <исходная_ветка> <целевая_ветка> -проверка что изменилось (т.к.бываем что меняется одна и таже строчка)
6. Удалить ветку git branch -d <название_ветки>
7. Просмотреть историю ветки git log



## Git для новичков (часть 1)

1. Git локально, Github-в сети
2. точка сохранения проекта-это commit
3. в проекте на жестком диске сначала создаем папку проекта, потом там создаем репозиторий, потом создаем .git с помощью команды gitinit, чтобы файлы отслеживать
4. чтобы файлы отслеживались используем файл git add all, либо конкретный файл с указанием в команде имени файла
5. дальше с помощью команды git commit -m "<комментарий>" коммитим
6. создаем ветки с помощью команды git branch, но помним что ветки создаются желательно на: новый функционал, на исправление ошибки, на улучшение кода
7. прыгаем с ветки на ветку с помощью команды git checkout 
8. GitHub Flow это рабочий процесс- создаем ветку, вносим изменения (пишем код, изменения, улучшения, исправляем ошибки), создаем коммит-описываем ЧТО мы сделали (изменили, внесли), отправляем запрос на слияние (на Пул Реквест (т.е просим грубо говоря код-ревью)), делаем изменения по замечаниям из код-ревью, при необходимости добавляем коммиты по ходу, согласовываем, утверждаем (апрув получаем (одобрение)), мержим с мейн, радуемся)))
9. git branch --show-current -команда возвращающая ветку, в которой я сейчас нахожусь-очень актуально с моей памятью)
