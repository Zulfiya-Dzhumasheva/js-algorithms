## Git для новичков (часть 1)

1. Git локально, Github-в сети
2. точка сохранения проекта-это commit
3. в проекте на жестком диске сначала создаем папку проекта, потом там создаем репозиторий, потом создаем .git с помощью команды gitinit, чтобы файлы отслеживать
4. чтобы файлы отслеживались используем файл git add all, либо конкретный файл с указанием в команде имени файла
5. дальше с помощью команды git commit -m "<комментарий>" коммитим
6. создаем ветки с помощью команды git branch, но помним что ветки создаются желательно на: новый функционал, на исправление ошибки, на улучшение кода
7. прыгаем с ветки на ветку с помощью команды git checkout
